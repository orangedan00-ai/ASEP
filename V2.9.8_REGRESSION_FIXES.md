# ASEP v2.9.7 — Regression Fixes

Fixed the two validation failures found on Kali:

1. `app/routes.py`
   - `cfg["root"]` can be a string.
   - Both Flask `template_folder` and `static_folder` now convert the root
     through `pathlib.Path` before joining paths.

2. UX version contract
   - Test contract and `release.json` now consistently expect/report `2.9.7`.

The package must be validated before installation.
