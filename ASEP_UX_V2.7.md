# ASEP v2.7 — Universal Security Intelligence UX

## Product identity
ASEP is a universal security intelligence and exploitation platform.
No individual tool or capability is the product identity.

## Primary workflow
UNDERSTAND → DISCOVER → ANALYZE → VALIDATE → EXPLOIT → POST-EXPLOIT → ACHIEVE

## Dashboard principles
The dashboard emphasizes:
- environment understanding
- attack graph
- evidence
- findings
- sessions
- recommended next actions
- tool execution as a secondary capability

The UI must not make any single exploitation framework the dominant product identity.

## Assistant behavior
ASEP Assistant explains:
1. what is known
2. what evidence supports it
3. what is uncertain
4. possible paths
5. recommended next validation/action
6. why that action is recommended
7. confidence and risk
8. whether operator approval is required

## Universal capability model
Tool capabilities are selected from the objective and evidence, not the other way around.
