# ASEP v2.4 Target Path & Passive Deep-Dive

When a newly discovered asset is outside configured scope or ownership is unclear:

1. Preserve the original observation.
2. Perform only passive/non-intrusive correlation using evidence already available to ASEP.
3. Build relationship/path hypotheses and confidence.
4. Do not actively scan, exploit, authenticate to, pivot through, or otherwise interact with the candidate.
5. Ask the user for explicit scope confirmation before active testing.
6. Record the decision and subsequent scope change in the audit trail.

In-scope assets may proceed through the normal evidence-driven execution pipeline.
