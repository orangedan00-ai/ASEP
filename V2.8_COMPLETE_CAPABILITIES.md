## Self-modifying lifecycle

DETECT → DIAGNOSE → PREVIEW → CHECKPOINT → PATCH → COMPILE → TEST → ACTIVATE
or
PATCH → FAIL → ROLLBACK

The self-modifying engine is restricted to the ASEP project root and records
a checkpoint for every change. Approval is required by default.

## Re-planning lifecycle

RESULT → FAILURE/BLOCK → UPDATE STATE → GENERATE ALTERNATIVES → RANK →
RECOMMEND NEXT ACTION → VALIDATE → NEW EVIDENCE → REPLAN

The planner does not blindly execute a new path.

## Runtime validation

`validate_build.sh` now:
- uses the selected Python interpreter consistently
- no longer imports Flask during engine-only unit tests
- detects missing Flask explicitly
- can bootstrap dependencies with `ASEP_AUTO_INSTALL=1`
- runs real Flask endpoint smoke tests when Flask is installed
- supports `ASEP_REQUIRE_RUNTIME=1` for strict CI/runtime validation

## Runtime fix
`validate_build.sh` automatically prefers `.venv/bin/python` when the ASEP virtual environment exists, preventing false Flask-missing results after installation.
